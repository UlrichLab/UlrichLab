# Hi, I'm F. Ulrich 👋

Building practical AI, data, automation, and music tools for macOS and Windows.

I enjoy turning real workflows into focused, approachable software—from AI
usage monitoring and lightweight data utilities to tools for electronic music
hardware.

## Featured projects

### [AI Usage Widget](https://github.com/UlrichLab/AI-Usage-Widget)

A cross-platform desktop widget for monitoring Claude, ChatGPT/Codex, and
Cursor usage on macOS and Windows.

### [DataManagement](https://github.com/UlrichLab/DataManagement)

A collection of dependency-free JavaScript tools for parsing, storing, and
viewing data, including an interactive browser-based showcase.

### [Arturia KeyStep mk2 MIDI to Preset Loader](https://github.com/UlrichLab/Arturia-Keystep-MK2-MIDI-TO-PRESET-LOADER)

A reverse-engineering project and browser prototype for transferring MIDI
patterns into Arturia KeyStep mk2 project files.
